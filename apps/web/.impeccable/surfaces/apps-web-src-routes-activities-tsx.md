# Activities: Signal Garden

Mode: Operate. Scope: local `/activities` route only. User selected Signal Garden prototype variant C for production.

## Job and evidence
Help Chrome users explore which websites Tabot observed them moving between, and when. Task: choose a period, follow an observed connection, inspect a website's locally derived time evidence. Graph is optional orientation; website list and selected details stay available without graph interpretation. Evidence comes from `buildActivityFlow` over extension-local events. Never infer intent/productivity, expose raw event/visit counts, or send browser history. Existing authorized Ask AI action remains optional.

## Direction
Signal Garden: three columns—websites, observed transitions, and recent time groups—connected by native SVG curves. Existing IBM Plex, white operational canvas, ink/green neutrals; garden field muted green, lavender selection, lime time nodes. Sample-only prototype behavior becomes real origin-safe aggregates. Keep graph to eight sites, eight transitions, three time groups; no force simulation, idle motion, new dependencies, remote icons, or route-wide event nodes. Site list and details carry keyboard-accessible alternatives. Mobile graph scrolls horizontally; document does not.

## Memorable moment
Select an observed connection and trace its path across websites and time; the local, in-memory quest marks that thread as followed without points or a fabricated reward.

## Constraints / open
Keep `/home` and landing unchanged. Empty/loading/degraded states must distinguish missing data from no activity. Ask AI receives only selected period and optional HTTP(S) origin. Real-history performance beyond bounded rendered summaries remains to validate against large local stores.
