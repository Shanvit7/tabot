# Chrome Web Store — Tabot

Draft Chrome Web Store listing and permission/privacy copy for the 0.2.2 extension release. Tabot's product direction is a browser activity data layer for AI-assisted work; the current beta supports local review and eight read-only assistant tools, not a context workspace or automation engine. Last updated: November 13, 2026. Prepared manifest version: 0.2.2. No store submission or publication performed.

## Store listing

- Name: Tabot
- Short description: Turn your Chrome activity into context for your AI assistant.
- Category: Productivity
- Language: English
- Single purpose: Collect Chrome activity for local review and authorized sharing of supported results with a connected AI assistant.
- Popup update: The popup provides current-page note controls, tracking controls, local capture management, and an elapsed tracking timer. Refresh screenshots to show the current beta.
- Feature update: Tabot is building a browser activity data layer for AI-assisted work. The current beta records browser activity, supports local search and review of retained pages, bounded excerpts and notes, and offers eight read-only ChatGPT tools for supported activity and note results. Reusable contexts and user-directed automations are future direction, not shipped features. Eligible page titles and short visible excerpts are captured automatically while tracking is active, filtered for selected sensitive patterns before persistence, and remain local. Titles are bounded to 512 characters; excerpts stay capped at four fragments.

## Permissions justification

| Permission | Type | User-facing reason |
| --- | --- | --- |
| `storage` | permission | Save tracking preferences, assistant connection settings, and the last foreground observation locally. |
| `tabs` | permission | Identify the selected tab and its URL for the local browsing timeline. |
| `webNavigation` | permission | Record main-frame page navigation for browsing context. |
| `windows` | permission | Distinguish the focused browser window from background/minimized windows so browsing time is not inflated. |
| `idle` (new) | permission | Stop counting browsing time when the device is idle or locked; Tabot does not collect general keystrokes or form values. |
| `alarms` | permission | Retry interrupted local writes and enforce the local page-evidence storage budget. |
| `offscreen` | permission | Host TalaDB's local database worker from an extension-owned page; browser activity stays on device. |
| `<all_urls>` | host permission | Observe page visibility and interaction signals across the websites included in the user's local browsing timeline. |

## Privacy and data use

- Page titles and excerpts are captured automatically on eligible visible pages while tracking is active; no per-site opt-in remains. Titles are trimmed, bounded to 512 characters, and filtered locally for selected OpenRedaction patterns before persistence for credentials, tokens, connection strings, payment-card PANs, CVV/expiry, bank/payment and some tax/business identifiers. Detection covers selected patterns and is not exhaustive. The content script filters selected patterns at ingestion, then saves at most four short visible fragments after page settle, viewport dwell, or trusted interaction; it does not snapshot pages, capture form/editor values, or run in incognito. Titles and excerpts remain local and are not available to assistant tools.
- Page excerpts have no time-based expiry. Oldest excerpts are removed only when the 25 MiB local page-evidence cap is exceeded. The popup can delete excerpts by site or all at once; capture continues while tracking is active.
- New event URLs are minimized before persistence: URL credentials, fragments and arbitrary query parameters are removed; selected sensitive-data patterns in retained paths/search phrases are redacted. On recognized search pages (Google, Bing, DuckDuckGo, Brave, Yahoo, Ecosia), only the search phrase is retained locally after pattern redaction; detection covers selected patterns only. Older history may predate this protection; existing records are not silently rewritten or deleted.
- Tab/window IDs, timestamps, selected-pattern-filtered search phrases from supported providers, and interaction signals remain local. Foreground sampling adds timestamps and browser focus/idle state, not form values, screenshots, or keystroke values. Page excerpts are a separate local evidence store; they do not alter activity metrics. Idle state is used to decide whether to sample, not saved as a new raw event type.
- Foreground session state is saved in session storage with its URL minimized before persistence. Activity and page evidence are stored locally in TalaDB on OPFS through the extension's offscreen database owner. Existing IndexedDB history is imported and retired after verification; a migration-only IndexedDB reader remains for profiles that have not upgraded. Browser history, URLs, page content, search terms, notes, and browsing activity are not uploaded automatically to Tabot's relay or PostHog.
- If PostHog is configured, the dashboard sends dashboard route pageviews; the extension sends only generic unhandled-error and local search-indexing-failure event names, platform, and extension release. The web SDK uses ephemeral in-memory anonymous IDs; the extension uses a fixed app-level distinct ID (not a per-install ID). No user identity, browsing URL, page content, error message, or stack is included. PostHog receives network request metadata; configure PostHog privacy/IP settings and disclose analytics before store publication.
- The optional authorized ChatGPT connection returns derived context or site-level aggregate metrics only for requested tools. Metrics contain HTTP(S) origins, estimated time, visits, active days, and aggregate site-to-site transitions, never raw events or favicons. Requested note titles/text use the selected sensitive-data patterns above; detection is not exhaustive. The preferred opaque page reference avoids sending a URL, but the legacy full-URL note selector sends the user-supplied URL with that request. Origins (including identifying subdomains) are not anonymized. The relay does not persist browser history or tool results. A user-initiated export shares the selected context with its chosen recipient.
- Authorized pattern discovery returns bounded derived summaries; selected-pattern lookup adds occurrence timestamps, supporting context identifiers and origin-only sequences, not raw events or page URLs. Confidence describes heuristic similarity, not user intent or productivity. Discovery and selected-pattern lookup cover all locally retained browsing stretches, matching the dashboard; deleted or uncaptured activity is unavailable. Only the bounded, sanitized results of authorized requests leave the device.
- Historical active-time estimates cannot reconstruct attention when old visibility/focus evidence is absent. Existing downloads must be exported again to receive the fix.
