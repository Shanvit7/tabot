# Tabot operational UI

`/home` is the primary local workspace, built around retrieval rather than graph interpretation. A visible website-name search spans all recorded activity. One most-recent activity has a clear View activity action; three earlier entries form a ruled list, with more available on request. `/home?context=<id>` opens that exact activity in a light, text-first detail view with validated website-homepage links. Missing IDs never fall back to another activity. Search survives opening an activity and returning. Explore connections is collapsed by default; opening it loads the Remotion/native SVG graph and session projection, closing it unmounts the graph. A scoped error boundary protects retrieval from optional-graph failures. Activity and recurring-pattern routes remain separate. White canvas, ink/green neutrals, self-hosted IBM Plex, no KPI grid or inferred task names. Manual JSONL export stays collapsed; assistants remain optional. Operational charts use existing renderers; no new graph or chart dependencies.

Landing retains the original neobrutalist brand: lime #bfff00, black/white, self-hosted IBM Plex, square borders and hard offset shadows. Plain browsing-activity copy replaces pipeline jargon. Landing typography uses a fluid 36–52px hero, 32–36px section headings, and 18px body copy; supporting copy and controls stay at least 16px. Two Remotion previews reproduce the current 400×600 extension popup (site connections and its real ChatGPT banner), not fictional timelines or sharing interfaces. Previews stay at most 400px wide, use the popup's actual palette and type scale, and disclose sample sites in a small caption. Prerendered static views, reduced-motion support, external pause controls and viewport-gated loading remain. Privacy facts distinguish local activity from authorized ChatGPT summaries leaving the device. See `.ulpi/design/landing.md`. The privacy route retains its original visual language. Extension popup remains separate. Operational CSS: `apps/web/src/styles/work.css`. See `.ulpi/design/work-trace-home.md` for graph relationship rules.
